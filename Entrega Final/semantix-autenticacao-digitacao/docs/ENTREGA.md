## Publicação futura no GitHub

1. Entre na sua conta e crie um repositório público, por exemplo `semantix-autenticacao-digitacao`.
2. Envie **o conteúdo da pasta do projeto**, incluindo as subpastas. Não envie apenas o ZIP: isso dificulta ler o README e visualizar o notebook. Não inclua a pasta externa de imagens para entrega ou este pacote duplicado.
3. Confira se README, relatório, notebook, código, CSV público e figuras abrem corretamente. Os arquivos de resultados comprimidos preservam as previsões para auditoria.
4. Registre a URL e faça os dois prints reais indicados acima.
5. Na aba da tarefa, envie as imagens e, se houver campo, inclua a URL do repositório. Verifique a confirmação da plataforma.

Também é possível publicar com Git ou GitHub Desktop. Não é necessário compartilhar senha ou token com ninguém.
